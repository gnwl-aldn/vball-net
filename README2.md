VballNet使い方

ディレクトリを移動
    cd ~/volleyball_project/vball-net
実行
    uv run src/imgLabel.py \
  --video_path ../clips/【0609_01_rally001（ラリー動画）】.mp4 \
  --csv_path ~/fast-volleyball-tracking-inference/output/【0609_01_rally001（ラリー動画）】/ball.csv



基本操作

マウスクリック：その位置にボールがあるとして座標を記録
n：次のフレームへ進む
p：前のフレームへ戻る
f：最初のフレームへ
l：最後のフレームへ
>：36フレーム早送り
<：36フレーム早戻し
s：ここまでの結果をCSVに保存
e：終了

基本の流れ

ボールが見えているフレームで、ボールの位置をクリック
nで次のフレームへ進む
また次のフレームでボールをクリック → nで進む、を繰り返す
最後まで終わったらsで保存 → eで終了


ボールが見える（既存ラベルが合っている）→ そのままn
ボールが見える（既存ラベルがずれている/間違っている）→ 左クリックで訂正 → n
ボールが見えない（誤検出が残っている）→ 中央クリックでクリア → n
ボールが見えない（すでに正しく「見えない」になっている）→ そのままn
